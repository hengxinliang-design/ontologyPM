# 演示项目与商机（全年运营到 2026-11-01）

本地预览库的项目与商机由 `backend/scripts/seed_demo.py` 生成（定义在 `backend/scripts/demo_projects.py`），叠加在示例快照（TPL149、ZMJ113 合同与 WDR101 商机，保持导入后未维护）之上。历史数据固定在 2026 年：合同按月签约、回款按月到账、经营成本按月录入、里程碑按实际日期完成；近期日期相对重建当天（文中 T），所以「5 天内到期」在任何一天重建都成立。员工工时见 [people-scenarios.md](people-scenarios.md)。

重建：删除 `backend/data/preview.sqlite3` 后启动本地后端（自动导入示例快照），再运行 `.venv/bin/python scripts/seed_demo.py`；脚本加载后逐项核对下表的预期。
